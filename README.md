# Kannada-MNIST
A 1 Day Project on a derivative of MNIST Data, where the Kannada Language is used instead or Arabic Numerals


model 1: Simply trained on given data set, 99.59333539009094

model 2: Trained on more additional data but images are shifted in x, y direction and some are zoomed in a little bit, 99.32236075401306

model 3: Trained on additional data but with binarization in image, becaue tinker canvas is also binary, 99.15007948875427
